# Guion comercial breve

## Frase de entrada

Mi tienda de barrio admin es un sistema local para tiendas, despensas, víveres y pequeños minimarkets. La idea es ayudar a que una tienda opere con más orden: inventario, compras, salidas internas, reportes, respaldos, caja opcional y fiado opcional.

## Explicación simple

El sistema no obliga a usar internet ni nube para operar. La información queda en la computadora del negocio y se pueden crear respaldos. La instalación real empieza limpia, pero existe una base de presentación con datos inventados para mirar cómo se vería el sistema cuando ya está en uso.

## Puntos fuertes

- Inventario con stock mínimo y stock objetivo.
- Compras para registrar entradas de mercadería.
- Ventas internas para descontar stock, sin reemplazar comprobantes autorizados.
- Reportes para detectar productos bajos o por comprar.
- Respaldos para proteger la información.
- Licencia ética: si vence, no se bloquea el acceso a la información; solo se limitan nuevas escrituras.
- Módulos opcionales de caja diaria y fiado.

## Cierre

La meta es que el dueño tenga una referencia clara del estado de su tienda y pueda crecer hacia una operación más parecida a un minimarket.
