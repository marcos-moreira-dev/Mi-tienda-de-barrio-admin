# Ruta oficial de prueba funcional

1. Abrir aplicación.
2. Pasar loading sin errores.
3. Revisar licencia activa o modo permitido.
4. Entrar a Productos.
5. Crear categoría y unidad.
6. Registrar proveedor.
7. Registrar producto con stock mínimo y objetivo.
8. Registrar compra/entrada.
9. Confirmar movimiento de inventario.
10. Registrar salida interna.
11. Generar reporte de productos por comprar.
12. Crear respaldo.
13. Abrir carpeta de reportes y respaldos.
14. Revisar ayuda contextual.
