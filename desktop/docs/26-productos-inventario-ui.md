# Productos / Inventario UI

La pantalla de productos introduce un formulario más amplio, pero mantiene estructura predecible.

## Principios UX/UI

- Buscador visible.
- Lista a la izquierda, formulario a la derecha.
- Combos de catálogos para evitar texto ambiguo.
- Stock mínimo y objetivo como base de futuros reportes.
- Banderas simples para lote, vencimiento, perecible y refrigerado.

## Nota de carcasa parametrizable

La pantalla pertenece al dominio de tienda, pero la carcasa y componentes usados siguen siendo reutilizables para otras aplicaciones locales.
