# Patrón CRUD

## Uso

Aplicar en productos, categorías, marcas, unidades, proveedores y clientes fiados si se activa el módulo.

## Estructura de pantalla

- Buscador visible.
- Filtros principales.
- Tabla central.
- Panel lateral o modal de formulario.
- Acciones: Nuevo, Editar, Desactivar, Guardar, Cancelar.

## Reglas

No eliminar físicamente entidades con historial. Usar estado activo/inactivo.

## Validaciones

Mostrar mensajes humanos y guardar detalle técnico en logs.
