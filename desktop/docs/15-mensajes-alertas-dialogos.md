# Mensajes, alertas y diálogos

## Principio

El usuario debe entender qué pasó, por qué importa y qué puede hacer.

## Tipos

- Información.
- Advertencia.
- Error recuperable.
- Confirmación delicada.
- Resultado exitoso.

## Ejemplo

Correcto: “No se puede vender más unidades de las disponibles.”

Incorrecto: “Constraint violation.”
