# Overview desktop

## Familias de pantalla

- **Login:** entrada controlada al sistema, licencia y usuario local si aplica.
- **Loading:** inicialización, verificación de base, configuración y licencia.
- **Shell:** navegación principal por módulos.
- **Catálogo:** lista con filtros, tabla y detalle.
- **Bandeja operativa:** operaciones con estado y acciones rápidas.
- **Expediente:** detalle profundo de producto/proveedor con historial.
- **Reportes:** generación, exportación y apertura de carpeta.
- **Configuración:** parámetros, datos del negocio, licencia y respaldos.
- **Ayuda/casos de uso:** explicación contextual integrada.

## Regla

Copiar patrones con criterio: mantener look profesional, componentes reutilizables y mensajes claros, pero ajustar texto, módulos y flujos al dominio de despensa.
