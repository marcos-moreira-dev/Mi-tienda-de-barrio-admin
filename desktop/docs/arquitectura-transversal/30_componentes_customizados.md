# Componentes customizados

## Componentes a reutilizar conceptualmente

- Botón primario/secundario/destructivo.
- Tarjeta de resumen.
- Tabla con filtros.
- Panel detalle.
- Toast/notificación.
- Diálogo de confirmación.
- Empty state.
- Badge de estado.
- Campo de búsqueda.
- Selector de archivo/carpeta.

## Componentes propios del rubro

- Indicador de bajo stock.
- Indicador de producto vencido/próximo a vencer.
- Tarjeta de producto con foto.
- Selector de proveedor sugerido.
- Botón “Generar lista de compra”.
- Botón “Crear respaldo ahora”.

## Regla visual

Sobrio, claro, no infantil. Las tarjetas y botones deben ayudar a operar, no decorar de más.
