# Shell, navegación y workspace

## Módulos visibles sugeridos

- Inicio.
- Productos.
- Compras.
- Salidas internas.
- Inventario.
- Reportes.
- Caja.
- Proveedores.
- Respaldo.
- Configuración.
- Ayuda.

## Principios

- Navegación simple.
- No saturar con submenús al inicio.
- Botones claros y textos de negocio.
- Acceso visible a respaldo.
- Indicadores suaves de bajo stock y licencia.
