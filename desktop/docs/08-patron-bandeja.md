# Patrón bandeja

## Uso

Aplicar para listas de atención: productos bajos, agotados, próximos a vencer, vencidos, respaldos pendientes y licencia próxima a vencer.

## Estructura

- Título operativo.
- Filtros rápidos.
- Lista priorizada.
- Acción principal por fila.
- Exportar si corresponde.

## Regla

Una bandeja debe responder: qué debo atender ahora y qué pasa si no lo hago.
