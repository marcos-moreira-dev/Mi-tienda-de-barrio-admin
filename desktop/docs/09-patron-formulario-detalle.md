# Patrón formulario-detalle

## Uso

Aplicar cuando una entidad requiere información agrupada, por ejemplo producto, proveedor, compra o licencia.

## Estructura

- Encabezado con nombre/estado.
- Secciones plegables o tarjetas.
- Campos obligatorios arriba.
- Historial o movimientos abajo.

## Regla

No saturar la pantalla inicial. Mostrar primero lo que el usuario necesita para decidir.
