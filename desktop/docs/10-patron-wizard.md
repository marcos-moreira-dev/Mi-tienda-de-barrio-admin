# Patrón wizard

## Uso

Aplicar en primera configuración, recepción de mercadería y restauración de respaldo.

## Pasos sugeridos

1. Contexto.
2. Datos principales.
3. Revisión.
4. Confirmación.
5. Resultado.

## Regla

Los wizards se usan para operaciones delicadas o poco frecuentes, no para tareas rápidas diarias.
