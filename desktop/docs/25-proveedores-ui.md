# Proveedores UI

La pantalla de proveedores sigue el patrón CRUD sobrio de los catálogos, con panel lateral explicativo y formulario de baja fricción.

## Principios UX/UI

- No pedir datos innecesarios.
- Permitir observaciones libres.
- No borrar proveedores: desactivar conserva trazabilidad.
- Usar lenguaje de negocio.
