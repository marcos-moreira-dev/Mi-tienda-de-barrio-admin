# Estilos, temas y CSS

## Criterio visual

Diseño sobrio, legible y de negocio pequeño. No infantilizar la interfaz.

## Reglas

- Botones grandes en acciones principales.
- Colores funcionales para bajo stock, vencimiento y error.
- Espaciado generoso.
- Tablas limpias.
- Tipografía clara.

## Herencia de referencias

Tomar como referencia los componentes customizados y shell de los proyectos base, adaptando al dominio de tienda.
