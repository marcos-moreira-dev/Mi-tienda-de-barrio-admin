# 01. BD canónica y objetivo

## Propósito

Definir el objetivo oficial de la base de datos local de **Mi tienda de barrio admin**.

## Objetivo funcional

La base de datos debe permitir que una tienda, despensa, bazar o local mixto pequeño pueda operar en una sola computadora con:

- productos;
- categorías, marcas y unidades;
- proveedores;
- compras o entradas de mercadería;
- movimientos de inventario;
- ventas internas no tributarias;
- mermas y retiros;
- reportes operativos;
- respaldos;
- configuración del negocio;
- licencia local;
- ayuda contextual;
- y capacidades opcionales de caja, fiado y lotes/vencimientos.

## Objetivo técnico

La base oficial de V001 será SQLite.

Debe ser local, autocontenida, entendible por humanos, compatible con JavaFX, compatible con reportes y suficientemente simple para una primera versión vendible.

## Límites oficiales

La V001 no incluye facturación electrónica SRI, integración directa con SRI, contabilidad formal, multi-sucursal, varias computadoras simultáneas, nube obligatoria, app móvil, lectores de código de barras obligatorios, balanzas ni auditoría forense.
