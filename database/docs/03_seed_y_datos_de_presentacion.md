# Seed y datos de presentación

## Regla de lenguaje

No llamar “demo” a los datos visibles del producto. Usar:

- datos de presentación;
- datos iniciales;
- catálogo base;
- ejemplos internos.

## Seeds recomendados

- Categorías comunes: víveres, bebidas, limpieza, aseo, lácteos, snacks, enlatados.
- Unidades: unidad, funda, caja, libra, kilogramo, litro, mililitro.
- Motivos de movimiento: compra, venta interna, ajuste, merma, vencimiento, daño, corrección.
- Métodos de pago: efectivo, transferencia, mixto.
