# Respaldos y restauración

Funciones:

- crear respaldo manual;
- abrir carpeta de respaldos;
- exportar base de datos;
- restaurar respaldo;
- advertir si no se respalda en varios días;
- registrar historial de respaldos.

Aunque la licencia venza, el usuario debe poder exportar y respaldar sus datos.

Antes de restaurar se debe crear un respaldo preventivo.
