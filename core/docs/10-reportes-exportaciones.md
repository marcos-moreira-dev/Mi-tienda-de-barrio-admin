# Reportes y exportaciones

## Reportes base

- productos bajos;
- productos agotados;
- productos por comprar;
- inventario general;
- compras por periodo;
- ventas internas por día;
- productos próximos a vencer;
- merma/retiro;
- cierre de caja si aplica;
- fiado si aplica.

Formatos: PDF para imprimir y CSV/Excel para manipular.

El reporte de productos por comprar es el reporte comercial más importante.
