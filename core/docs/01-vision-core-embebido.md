# Visión del core embebido

El core embebido contiene casos de uso, servicios de aplicación, reglas de negocio, validaciones, acceso ordenado a repositorios, resultados de operación, errores locales y coordinación de transacciones.

No es backend HTTP, API REST, Spring Boot, servidor local, módulo web ni capa de presentación.

## Principio

> Todo lo que sea regla de negocio debe vivir fuera del controlador JavaFX.
