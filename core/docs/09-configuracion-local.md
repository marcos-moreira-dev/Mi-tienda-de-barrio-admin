# Configuración local

Centraliza datos del negocio y preferencias operativas.

## Datos del negocio

- nombre comercial;
- responsable;
- RUC opcional;
- teléfono;
- dirección;
- actividad;
- observaciones de permisos.

## Preferencias

- moneda;
- ruta de respaldos;
- ruta de reportes;
- días para alerta de vencimiento;
- días para advertir respaldo atrasado;
- activar/desactivar caja;
- activar/desactivar fiado;
- activar/desactivar lotes/vencimientos avanzados.
