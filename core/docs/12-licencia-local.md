# Licencia local

## Objetivo

Proteger el modelo comercial sin secuestrar datos.

## Modelo recomendado

- licencia local renovable;
- código o archivo firmado;
- fecha de vencimiento;
- aviso antes de vencer;
- periodo de gracia;
- modo limitado ético.

Si la licencia vence, permitir consultar, generar reportes básicos, exportar y crear respaldos. Limitar nuevas operaciones, no borrar información.
