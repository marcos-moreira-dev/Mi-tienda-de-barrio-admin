# Validaciones y errores

## Principio

Mensajes entendibles para dueño/empleado. Logs técnicos separados.

## Producto

Nombre obligatorio, stock no negativo, stock objetivo mayor o igual al mínimo, precios no negativos.

## Compra

Al menos un producto, cantidad mayor a cero, costo no negativo, fecha válida.

## Salida

Cantidad mayor a cero, stock suficiente salvo ajuste, motivo obligatorio para merma/daño/vencimiento.

## Respaldo

Validar archivo antes de restaurar y pedir confirmación.

## Licencia

Código inválido, licencia vencida, próxima a vencer y licencia aplicada.

## Mensaje técnico transformado

> No se pudo guardar la operación. Revise los datos e intente nuevamente. Si continúa, contacte soporte.
