# Experiencia de usuario

## Principio

La app debe sentirse como herramienta de trabajo, no como software académico.

## Criterios

- Botones claros.
- Buscador visible.
- Pocas acciones por pantalla.
- Tablas legibles.
- Mensajes humanos.
- Ayuda contextual.
- Colores funcionales.
- Diseño sobrio.
- Acceso visible a respaldo.

## Patrones UI

- CRUD: productos, proveedores, categorías.
- Wizard: primera configuración o recepción de mercadería.
- Bandeja: productos bajos, vencidos o por comprar.
- Expediente: detalle de producto/proveedor si aporta.
- Reportes: filtros + tabla + exportar.

## Login y loading

Se pueden adaptar de proyectos anteriores. Login no debe complicar V1 si no hay usuarios reales. Loading debe informar base, configuración, licencia y módulos.
