# Modelo comercial y licenciamiento

## Objetivo

Hacer rentable el producto sin dañar la relación con el cliente ni bloquear sus datos.

## Modelos posibles

### Pago único

Cliente paga instalación y alcance definido. Soporte y cambios se cobran aparte.

### Instalación + licencia

Pago inicial por instalación y licencia renovable mensual, trimestral, semestral o anual.

### Rent-to-own

Pago inicial bajo más cuotas por varios meses. Al finalizar, el cliente conserva licencia permanente básica. Soporte se cobra aparte.

### Soporte por evento

Sin mensualidad, pero cada visita, recuperación, cambio o capacitación adicional tiene costo.

## Licencia local recomendada

- Código o archivo de licencia firmado.
- Fecha de vencimiento.
- Aviso antes de vencer.
- Periodo de gracia.
- Renovación manual sin internet.
- Verificación ocasional por internet solo si el cliente acepta.

## Modo limitado ético

Si la licencia vence:

- permitir consultar datos;
- permitir exportar reportes;
- permitir respaldar;
- limitar nuevas operaciones;
- mostrar aviso de renovación.

Nunca borrar, cifrar ni bloquear la información del cliente.

## Regla de reputación

Un sistema local para barrio vive de confianza. La licencia debe proteger al desarrollador, pero no parecer extorsiva.
