# Alcance vendible

## Incluye V1

- Configuración del negocio.
- Productos.
- Categorías, marcas y unidades.
- Proveedores.
- Compras/entradas.
- Movimientos de inventario.
- Salidas/ventas internas no tributarias.
- Reportes.
- Respaldos/restauración.
- Licencia local.
- Ayuda contextual.

## Opcional local

- Caja diaria.
- Fiado/cuentas por cobrar.
- Checklist de recepción.
- Lote/vencimiento avanzado.
- Foto de evidencia en recepción.

## Fuera de V1

- Facturación electrónica.
- Integración SRI.
- Nube obligatoria.
- App móvil.
- Varias computadoras.
- Multi-sucursal.
- Contabilidad formal.
- Integración bancaria.
- Tienda online.
- Balanzas.
- Lectores de código de barras obligatorios.
- Auditoría empresarial avanzada.

## Regla comercial

Si el cliente quiere bajar precio, se baja alcance. Si quiere mantener alcance, se mantiene precio. Si pide varias computadoras, facturación o nube, se cotiza como transición avanzada.

## Frase de venta

> Esta versión está pensada para una tienda pequeña que quiere ordenar productos, compras, stock y reportes en una sola computadora. Si su negocio crece, se puede plantear una etapa más avanzada.
