# Documentación del proyecto

Esta carpeta es la fuente principal para entender el producto antes de programarlo.

## Secciones

- `general/`: reglas de verdad, principios y mapa documental.
- `rubro-despensa/`: investigación y traducción del rubro a requisitos.
- `producto/`: alcance, módulos, roadmap y promesa comercial.
- `arquitectura/`: decisiones técnicas JavaFX + SQLite.
- `modulos/`: documentación funcional por módulo.
- `ux-ui/`: patrones de interfaz, login, loading, shell y componentes.
- `comercial/`: licenciamiento, negociación, precios y límites.
- `decisiones/`: ADRs y decisiones arquitectónicas/comerciales.

## Regla documental

Cada módulo debe tener al menos:

- propósito;
- casos de uso;
- datos principales;
- flujos operativos;
- componentes UI;
- mensajes y errores;
- pruebas manuales;
- límites de alcance.
