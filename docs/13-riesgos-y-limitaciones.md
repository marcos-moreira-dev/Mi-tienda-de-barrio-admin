# Riesgos y limitaciones

## Comerciales

Cliente pide todo por poco, no paga licencia, espera SRI, usa varias PC o no respeta alcance.

## Técnicos

Apagones, disco dañado, base corrupta, no hacer respaldos, computadora lenta, imágenes pesadas.

## De uso

No registrar compras/salidas correctamente, abandonar sistema, confundir venta interna con factura.

## Mitigación

Alcance escrito, capacitación, backups, mensajes claros, soporte por etapa, modo limitado ético y transición avanzada.
