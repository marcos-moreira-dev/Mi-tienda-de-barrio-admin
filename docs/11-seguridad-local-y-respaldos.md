# Seguridad local y respaldos

## Riesgo principal

El sistema local depende de una computadora. Si se daña el disco o hay apagones, se necesita respaldo.

## Medidas

- Backup manual de un clic.
- Historial de respaldos.
- Recordatorio por días sin respaldo.
- Restauración guiada.
- Carpeta de respaldos visible.
- Recomendación de copia externa.

## Apagones

Usar transacciones, no manipular archivos WAL/journal manualmente, cerrar app correctamente cuando sea posible y respaldar con frecuencia.

## Licencia

No debe bloquear datos. Datos del cliente siguen accesibles para consulta, exportación y backup.
