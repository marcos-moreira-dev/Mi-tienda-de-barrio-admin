# Scripts de empaquetado

## Propósito

Documentar el futuro empaquetado de la aplicación local.

## Herramienta esperada

`jpackage`, con runtime incluido para evitar que el cliente instale Java manualmente.

## Scripts previstos

- `package-runtime.bat`
- `package-installer.bat`
- `verify-package.bat`

## Salida esperada

Un instalador local para Windows y una carpeta de distribución controlada.
