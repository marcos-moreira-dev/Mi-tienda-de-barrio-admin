# Glosario del dominio

- **Stock actual:** cantidad registrada.
- **Stock mínimo:** nivel que dispara alerta.
- **Stock objetivo:** cantidad deseada luego de reponer.
- **Merma:** pérdida por daño, vencimiento o retiro.
- **Lote:** partida identificable.
- **Venta interna:** salida operativa no tributaria.
- **Caja diaria:** control simple de efectivo.
- **Fiado:** deuda informal del cliente.
- **Respaldo:** copia de base local.
- **Modo limitado:** estado por licencia vencida que permite consultar/exportar/respaldar.
